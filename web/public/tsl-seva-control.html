Data Security — How Your Temple Data Is Protected
1
Temple Slug Lock

Every page URL contains your temple's unique slug. The server only shows data that belongs to this slug. No other temple can see it.

2
Session Binding

When you log in, your session is locked to your temple. Even if someone guesses your login token, the server checks that the token belongs to the correct temple.

3
Database Filtering

Every database query includes a temple filter. There is no code path that returns data from a different temple. It is physically impossible for one temple's data to appear in another temple's view.

4
Audit Trail

Every action — who did what, when, what changed — is logged with before/after JSON snapshots. Nothing can be modified silently.
